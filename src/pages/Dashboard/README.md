# 홈(구 대시보드) (`/`)

첫 화면. 헤더 바로 아래 파란 띠(히어로)에 최근 추천 결과를(없으면 소개와 계산 버튼을) 보여 주고, 아래에 관심 동네와 지원 공고를 둡니다.

- 파일: `Dashboard.jsx`, `Dashboard.css`
- 상태: `useAppState()`의 `favs`(dong_code), `favIndustry`, `addFav` · `removeFav`, `last` / 로컬 `undo`(방금 해제한 동 · 업종 · 원래 위치)
- API: ① 마감임박 공고, ⑤ 최근 추천 갱신(ts-last의 rec_id), ⑫ 관심 카드(카드마다 dong_code + 그 동의 업종), 동 이름 · 구 이름도 ⑫(dong_name · district_name), 업종을 모르는 카드만 ⑧ · ⑨(`lib/dongNames`), 업종명은 ⑩
- 색: 파랑(primary)이 기본. 민트(`--accent`)는 띠의 빛 · 아이콘 타일 · 섹션 포인트에만 쓰고, 데이터 값 색(상승 초록 · 하락 빨강)과 섞지 않습니다. 띠 안에서만 증감 색을 밝은 톤으로 바꿉니다(`.is-result`가 `--green` · `--down` · `--muted`를 덮어씀).
- 아이콘: `components/ui`의 `Icon`(SVG 선 아이콘). 글자 기호(↗ ⇄ ✦ ?)는 쓰지 않습니다.
- 움직임: 들어올 때 짧은 페이드업(`fade-up`, `--ease-out`). `prefers-reduced-motion`이면 전부 멈춥니다(global.css).
- 폭: 대시보드만 최대 1440px(다른 화면은 1160px). 띠 배경은 화면 끝까지, 띠 안 내용은 아래 카드와 같은 폭 · 여백에 맞춥니다.

## 요소

### 0. 상단 바
데스크톱은 공용 헤더(로고 왼쪽 · 메뉴 가운데, 높이 76px). 모바일은 로고만 있는 상단 바.

### 1. 히어로 띠 (`.dash-hero`)
진한 파랑 ↔ 남보라 그라데이션이 24초 주기로 천천히 흐르고(`hero-flow`), 민트 · 하늘 빛 두 덩어리가 오른쪽 영역만 떠다닙니다(`::before` · `::after`, transform만). 흰 글자 대비를 위해 바탕 밝기는 L 0.36~0.47로 묶습니다.

#### 추천 결과가 없을 때 (`.is-intro`)
| 요소 | 내용 |
|---|---|
| 머리말 | "서울 청년 창업 입지 추천" — 배지 없이 얇은 글자 |
| 제목 (`RotatingHeadline`) | 5문장이 6초마다 바뀜(위로 사라지고 아래에서 올라옴). 모든 문장을 한 칸에 겹쳐 높이를 고정해 아래 내용이 움직이지 않음. 마우스를 올리면 멈추고, 동작 줄이기면 첫 문장에 머묾. 화면 읽기는 지금 문장만 |
| 설명 | 내 자본금과 받을 수 있는 지원금으로 갈 수 있는 구와 동네를 찾아 드려요. |
| 버튼 | [새 조건으로 계산하기 →] `/recommend` · [지도로 찾아보기] `/search` |
| 숫자 칩 3개 | 관심 창업지 N곳(`#dash-favs`) · 모집 중 공고 N건 · 7일 내 마감 N건(`#dash-notices`). 받아 둔 공고를 세기만 함. 받는 중이면 `…`, 공고 오류면 공고 칩 2개를 숨김 |

#### 추천 결과가 있을 때 (`.is-result`)
왼쪽은 1위를 큰 글씨로, 오른쪽은 내 예산으로 갈 수 있는 구 수와 2~5위 표. **카드 클릭 동작 없음**(링크 · 버튼만).

| 요소 | 내용 |
|---|---|
| 머리말 | "최근 추천 결과 · `last.date`" |
| 1위 | 종합점수 링(점수/100 비율을 그리기만, 없으면 빈 링에 —. 점수는 어디서나 소수 첫째 자리 `82.0` — `lib/format` scoreText) + 민트 **1위** 배지 · "업종 추천" + 동 이름(큰 제목) · 구 |
| 지표 (`.res-stats`) | 영업 유지(3년 확률 + 1년, 없으면 점포 수 증감) · 예상 월매출 · 성장세 · **예산 여유**(`last.margins[구 코드]`, 키가 없으면 칸을 숨기고 null이면 정보 없음). 구분선으로 나눈 한 줄, 좁으면 2×2. '신뢰도 낮음'은 값 아래가 아니라 항목 이름 옆에 `● 신뢰도 낮음` |
| 버튼 | [상세 분석 보기 →] 1위 동 상세(`from=rec`) · [새 조건으로 다시 계산] `/recommend`(좁으면 "다시 계산") |
| 2~5위 표 (`.res-side`) | 맨 위에 "내 예산으로 갈 수 있는 구 N / 25"(`passCount`), 그 아래 동네(구) · 예상 월매출 · 성장세 · 점수. [전체 결과 보기 ›] `/recommend?step=3` |

### 2. 관심 등록한 창업지 (`#dash-favs`)
하트 아이콘 + 제목 + 개수 pill, 1곳 이상이면 오른쪽에 [나란히 비교하기 ›] `/compare`.

좁은 화면에서는 폭 270px 카드의 가로 스크롤(scroll-snap, 페이지 여백 끝까지), 넓은 화면(컨테이너 900px~)에서는 격자(`minmax(280px, 1fr)`). 마지막 칸은 점선 [+ 동네 더 담기] `/search`.

| 요소 | 내용 |
|---|---|
| 카드 전체 | 상세로 이동(링크의 `::after`가 카드를 덮음), hover 시 떠오름 |
| 이름 · 구 · 업종 | 주거지역이면 보라 배지 |
| 종합점수 | 24px, 예측 불가면 — |
| ♥ 버튼 | 관심 해제 → 하단 토스트. 링크 위에 떠 있어 카드 이동이 일어나지 않음 |
| 지표 3칸 | 3년 영업 유지(확률 + 1년, 없으면 "점포 수 증감" + "점포 N곳") · 월매출(만) · 성장세. 좁은 칸이라 이름 · 보조 줄을 짧게 쓰고 원래 이름은 title로 |
| 신뢰도 낮음 | 해당 항목 이름 옆 주황 점(`LowDot`, 마우스를 올리면 이유) + 카드 아래 한 줄 "● 신뢰도 낮음 · 자료가 적거나 상권 기준이 바뀌었어요" |

관심이 0곳이면 하트 아이콘 타일 + 안내 문구 + [지도로 찾아보기] `/search`.

### 3. 청년 창업 지원 일정 (`#dash-notices`)
달력 아이콘 + 제목. `status`로 두 묶음으로 가른다(카드 하나, 넓으면 "지금 모집 중 | 올해 마감" 두 칸). 행 전체가 새 탭 링크(원문 `source_url`).
- **지금 모집 중**(민트 점) — 서버 순서 그대로(마감 가까운 순).
- **올해 마감 · 내년 같은 시기 모집 예상**(회색 점) — **다음 모집 예상 연 · 월이 가까운 순 → 최대 금액 큰 순 → 서버 순서**, 행 전체를 흐리게. 처음 3건, "더 보기 (n)"로 나머지(펼친 행도 페이드인).
- **모집 중이 0건이면** 왼쪽 칸을 숨기고 마감 묶음을 한 칸 전체 폭(`.notice-card.single`)으로 보여 준다. 묶음 위에 회색 안내 박스(`.notice-guide`) "지금은 모집 기간이 아니에요. 서울 청년 창업 현금 지원은 대부분 1~5월에 열려요. 내년 일정을 미리 확인하세요.", 묶음 제목은 "다음 모집 예상 · 가까운 순".
- **다음 모집 예상 연 · 월**(`lib/schedule.js` `nextExpectedMonth`) — 기준 월은 `apply_start`의 월(없으면 `apply_end`의 월). 오늘(KST) 달보다 뒤면 올해, 같거나 앞이면 내년. 예(2026-11-21): 5월 → 2027년 5월, 11월 → 2027년 11월. TODO(가정): 공고가 매년 같은 달에 다시 열린다는 가정의 표시용 계산(QUESTIONS.md).

| 요소 | 내용 |
|---|---|
| 상태 칩 | 폭 52px 고정. 모집 중이면 `D-n`(7일 이하면 빨간 바탕 흰 글자, 마감일이 없으면 민트 "모집 중"), 마감이면 옅은 파랑 "올해 예상"(예상 연도 = 오늘(KST) 연도) 또는 "내년 예상"(예상 연도 > 오늘 연도) — `lib/schedule.js` `expectedYearLabel` |
| 제목 · 기관 · 지원 규모 | |
| 마감일 | 모집 중 `MM.DD 마감`, 마감 `YYYY년 N월경`(다음 모집 예상) (420px 미만에서 숨김 — 마감 행은 기관 · 금액 줄 끝에 ` · YYYY년 N월경`) · 바깥 링크 아이콘(hover 때 파랑으로 살짝 밀림) |
| 공고를 찾을 수 없음 (`PROGRAM_NOT_FOUND`) | 목록 자리의 박스에 "공고를 찾을 수 없어요" · "잠시 후 다시 시도해 주세요." · [다시 시도]. 개발 서버에서 `?fail=program_not_found`로 확인 |

스크롤 연동을 지원하는 브라우저에서는 관심 · 공고 섹션이 화면에 들어오는 동안 페이드업(`animation-timeline: view()`), 아니면 처음 열 때 한 번 페이드업.

### 4. 되돌리기 토스트
"○○을(를) 관심 목록에서 뺐어요" + [되돌리기]. 아래에서 올라오고, 4초 뒤(또는 되돌리기 후) 다시 내려가며 사라집니다(`usePresence`로 나가는 동안 붙잡아 둠, 그동안은 눌리지 않음). 모바일은 탭바 위 12px, 데스크톱은 하단 24px.
