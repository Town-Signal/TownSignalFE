# 대시보드 (`/`)

첫 화면. 최근 추천 결과, 주요 기능 바로가기, 관심 동네, 지원 공고를 한 번에 보여 줍니다.

- 파일: `Dashboard.jsx`, `Dashboard.css`
- 상태: `useAppState()`의 `favs`, `last`, `toggleFav` / 로컬 `undo`(방금 해제한 동 이름)
- 계산: `dongInfo`, `dongPath`, `growthColor`, `notices`, `fmt`

## 요소

### 0. 모바일 상단 바
로고 + "타운시그널". 데스크톱에서는 공용 헤더가 대신합니다.

### 1. 인사말 (`.dash-greet`)
"가게 열 동네, 감 말고 데이터로 정해요". 글자 크기 `clamp(22px, 3cqw, 30px)`.

### 2. 최근 추천 결과 (`.dash-last`)
`last`가 있을 때만 보입니다. **클릭 동작 없음** (하단 링크만).

| 요소 | 내용 |
|---|---|
| 제목 / 날짜 | "최근 추천 결과" / `last.date` (예: 10월 2일) |
| 감당 가능한 구 | `last.passCount` / 25 (초록 26px) |
| 1위 카드 (`.dash-first`) | "1위 추천" 태그, 동 이름(24px), 구, 종합점수(40px), 지표 3줄: 예상 생존(중앙값 개월) · 예상 월매출(중앙값) · 성장세(상승 초록 / 하락 빨강 / 없으면 —) |
| 2~5위 목록 (`.dash-rest`) | 순위 배지, 동 이름·구, 성장세, 점수 |
| 전체 결과 보기 › | `/recommend?step=3` |

`last`가 없으면 빈 상태 카드: "?" 아이콘, "아직 추천받은 결과가 없어요", 안내 문구.

### 3. 바로가기 (`.dash-shortcuts`)
세로 3칸. 데스크톱에서는 왼쪽 카드와 높이가 같고 첫 칸이 2배(`flex: 2`).

| 버튼 | 활성 조건 | 동작 |
|---|---|---|
| 새 조건으로 계산하기 (primary, ✦ 장식 2개) | 항상 | `/recommend` |
| 상세 분석 바로가기 (↗) | `last` 있음 | 최근 1위 동의 상세 (`from=rec`) |
| 관심 상권 비교하기 (⇄) | 관심 1곳 이상, "관심 N곳 나란히 보기" | `/compare` |

조건이 안 맞으면 회색 비활성 카드(아이콘 숨김, `cursor: not-allowed`)와 안내 문구("추천을 받으면 1위 동네를 바로 볼 수 있어요" / "관심 동네를 1곳 이상 담아 주세요").

### 4. 관심 등록한 창업지 (`.fav-scroll`)
제목 옆에 개수(primary). 폭 270px 카드의 가로 스크롤(scroll-snap), 페이지 여백 끝까지 붙습니다.

| 요소 | 내용 |
|---|---|
| 카드 전체 | 상세로 이동 (링크의 `::after`가 카드를 덮음), hover 시 떠오름 |
| 이름 · 구 | 주거지역이면 보라 배지 |
| 종합점수 | 24px, 예측 불가면 — |
| ♥ 버튼 | 관심 해제 → 하단 토스트. 링크 위에 떠 있어 카드 이동이 일어나지 않음 |
| 지표 3칸 | 생존(개월) · 월매출(만) · 성장세(+ "신뢰도 낮음" 배지) |

관심이 0곳이면 안내 문구 + "동네 찾아보기 ›"(`/search`).

### 5. 청년 창업 지원 공고 (`.notice-list`)
마감 임박 순, 상시모집은 뒤. 행 전체가 새 탭 링크.

| 요소 | 내용 |
|---|---|
| D-day 칩 | `D-n`. 7일 이하면 빨간 강조, 상시모집은 초록 칩 |
| 제목 · 기관 · 지원 규모 | |
| 마감일 | `MM.DD 마감` (420px 미만에서 숨김) · ↗ |

### 6. 되돌리기 토스트
"○○을(를) 관심 목록에서 뺐어요" + [되돌리기]. 4초 뒤 사라집니다. 모바일은 탭바 위, 데스크톱은 하단 16px.

## 반응형

| 폭 | 레이아웃 |
|---|---|
| 900px 이상 | 최근 결과 1.6 : 바로가기 1 두 열 |
| 900px 미만 | 한 열로 쌓임 (최근 결과 → 바로가기) |
| 520px 미만 | 1위 카드와 2~5위 목록도 세로로 쌓임 |
