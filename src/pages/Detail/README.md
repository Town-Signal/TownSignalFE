# 상세 분석 (`/dong/:name?from=rec|search&sub=업종`)

한 행정동의 예측·성장세·임대료·업종 분포·매출 추이·유동 인구를 보여 줍니다.

- 파일: `Detail.jsx`, `SalesTrend.jsx`, `FootTraffic.jsx`, `Detail.css`
- 입력: 경로의 동 이름, `from`(뒤로가기 목적지), `sub`(없으면 최근 추천 업종 → 커피전문점)
- 상태: 전역 `favs`, `last` / 차트 내부의 hover·성별 필터
- 계산: `dongInfo`, `detailExtra`, `marginOf`

## 요소

### 1. 상단
| 요소 | 내용 |
|---|---|
| 모바일 상단 바 | ‹ 뒤로 · "행정동 상세" · ♡ |
| 뒤로 버튼 (데스크톱) | 원형 ‹ |
| 뒤로 동작 | `from=rec` → 추천 3단계(이 동 선택 상태) / 앱 안에서 들어왔으면 이전 화면 / 주소로 바로 들어왔으면 `from=search` → 직접찾기, 그 외 → 대시보드 |
| 동 이름 | `clamp(28px, 4cqw, 38px)`, 주거지역 배지 |
| 태그 | 구 · 업종 |
| 종합점수 | 44px + "종합점수 / 100". 예측 불가면 — |
| ♡ (데스크톱) | 48px 원형. 현재 업종과 함께 관심 등록 |

### 2. AI 요약 (`.ai-summary`)
그라데이션 배경이 천천히 움직이는 카드. "AI가 분석하여 생성한 문장이에요" + 한 문단. 문장은 상태에 따라 넷 중 하나: 표본 부족 / 예측 불가 / 주거지역 / 일반(점수 70 이상 "균형이 좋은", 55 이상 "무난한", 그 아래 "신중히 볼 필요가 있는").

### 3. 예상 생존 기간 · 예상 월매출 (`.pred`)
| 상태 | 내용 |
|---|---|
| 예측 가능 | 지표마다 중앙값(22px) + 범위 막대(연파랑 = 80% 범위, 진파랑 눈금 = 중앙값) + "80% 범위 a~b" |
| 예측 불가 (회기동) | 점선 상자: "예측 불가" · "○○ 예측에 필요한 데이터가 부족해요" |
| 표본 부족 (선택 업종 점포 5곳 미만) | "표본이 적어 신뢰할 수 없음" · "○○ 점포가 평균 N곳뿐이라 예측하기 어려워요", 종합점수도 — |

하단에 참고용 안내.

### 4. 성장세 · 예산 여유 · 임대료 (`.detail-side`)
| 카드 | 내용 |
|---|---|
| 성장세 | 증감률(상승 초록 / 하락 빨강) 또는 "정보 없음". 가산동·방학3동은 "신뢰도 낮음" 배지와 사유 |
| 예산 여유 | **추천 이력(`last`)이 있을 때만 표시.** 구 기준 금액(음수면 빨강) 또는 "정보 없음", 계산 설명 |
| 임대료 | 구 평균 월세. 금천구·강북구는 "신뢰도 낮음", 도봉구는 "정보 없음" + 사유 |

### 5. 업종 분포 (`.dist`)
점포 수 상위 8개 업종(+ 선택 업종이 빠졌으면 추가). 행마다 업종명(선택 업종은 파랑 굵게), 3칸 수준 막대, 적음/보통/많음. 범례에 마우스를 올리면 기준 설명.

### 6. 최근 매출 추이 (`SalesTrend`)
| 요소 | 내용 |
|---|---|
| 차트 | 분기별 점포당 월평균 꺾은선 + 아래 영역 그라데이션, 진입 시 아래에서 솟는 애니메이션 |
| 점 | 올리거나 누르면 커지고 점선 가이드 + 말풍선(분기, 금액) |
| x축 라벨 | 24.3Q ~ 26.2Q. 데이터가 없는 분기는 흐리게(가산동은 최근 3개 분기만) |
| 하단 | "최근 분기 점포당 월평균이에요 **N만 원**" |

### 7. 유동 인구 (`FootTraffic`)
| 요소 | 내용 |
|---|---|
| 제목 옆 | "○○대가 가장 많아요" (성별 필터 시 "○○대 남성이 …") |
| 성별 비율 막대 | 남성(파랑) / 여성(분홍) |
| 성별 칩 | "남성 n%" / "여성 n%". 누르면 그 성별만, 다시 누르거나 [전체 보기]로 해제 |
| 연령 막대 6개 | 10대 ~ 60대+. 가장 높은 막대만 진하게. 올리거나 누르면 말풍선(전체의 n% + 남/여 비율, 필터 중이면 "남성 중 n%") |

### 8. 하단 CTA (`.detail-cta`)
"○○, 다른 곳과도 견줘볼까요?" + [다른 추천 동네 보기](`from=rec`) 또는 [다른 동네 검색] + [관심 상권과 비교하기 ›].

## 반응형

| 폭 | 격자 |
|---|---|
| 1180px 이상 | 6칸. 윗줄: 예측(2) · 성장/예산/임대(2) · 업종 분포(2), 아랫줄: 매출 추이(3) · 유동 인구(3) |
| 720~1179px | 2열. 예측 카드는 전체 폭에 두 지표 나란히 |
| 720px 미만 | 1열 |

성장세·예산 여유 카드는 `auto-fit`이라 좁으면 세로로 쌓이고, 숫자 크기는 카드 폭(`cqw`)에 맞춰 줄어듭니다.

## 예외

- 없는 동 이름이거나 점포 데이터가 없는 동이면 "○○ 데이터가 없어요" + [직접 찾아보기].
