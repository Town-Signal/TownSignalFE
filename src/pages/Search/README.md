# 직접찾기 (`/search?q=검색어`)

지도에서 행정동을 직접 고르거나 검색해 업종별 점수와 요약을 봅니다(명세 10.4).

- 파일: `Search.jsx`, `Search.css`
- API: ⑩ 업종(`lib/masters`), ⑱ 업종별 랭킹(지도 색칠 · 상위 목록), ⑦ 자동완성, ⑧ 자치구 · ⑨ 행정동(대안 경로), ⑫ 선택 동 카드
- 상태(로컬): `query`, `sugs`(⑦ 결과), `picked`(선택한 동: dong_code · 이름 · 구 · geo_code), `industryCode`, `browse`(구에서 고르기), `sheetOpen`(모바일 시트), `more`
- 지도: `DongLeafletMap`(지연 로딩) — 동 경계를 ⑱ total_score 5단계로 색칠, 상위 10곳 + 선택 동에 핀. 경계와는 geo_code로 잇는다

## 요소

| 요소 | 내용 |
|---|---|
| 검색창 | 공백을 뺀 1자 이상이면 200ms 뒤 ⑦(최대 8건). 일치 부분 굵게 + 구 이름(이름이 같은 동 구분). ↑↓ · Enter, × 지우기. 일치 없음 → "‘검색어’와 일치하는 서울 행정동이 없어요" |
| 업종 고르기 | 한 줄 버튼(`업종 외식업 › 분식전문점 ▾`, `IndustryPicker`). 누르면 아래 목록 위에 뜨는 드롭다운(흰 바탕 · 테두리 · 그림자, 자동완성과 같은 모양 — 목록을 밀어내지 않음)에서 이름 검색 · 대분류 탭(개수) · 여러 줄 세부 칩(많으면 그 안에서 스크롤)으로 고르고, 고르거나 바깥 · Esc면 닫힌다. 매출 없는 업종도 남겨 대분류마다 40개가 넘어 가로 칩 줄 대신 이렇게. 기본은 ts-cond의 업종, 없으면 첫 업종. 바꾸면 ⑱ · ⑫를 다시 부른다 |
| 상위 목록 | ⑱ 앞 5곳(10위까지 보기 / 접기, 데스크톱은 처음부터 10곳): 순위 · 동명 · 구명 · 성장세 · 점수. 데스크톱 줄 높이 64px. "구에서 고르기 ›" → ⑧ 자치구 5칸 × 5줄 격자(가나다순, 스크롤 없이 다 보임) → ⑨ 행정동 목록(줄마다 지금 업종 순위 · 점수, 돌아가기는 제목 왼쪽 ‹) |
| 지도 | 동 클릭 · 핀 클릭 → 선택, 구 클릭 → 그 구의 ⑨ 목록 |
| 선택 동 카드 | ⑫ 종합점수 · 영업 유지(3년 영업 유지 확률 + 1년, 없으면 점포 수 증감) · 예상 월매출(중앙값 + 80% 범위) · 성장세 · 점포 수준(적음/보통/많음 · 점포 N곳) · ♡ · 맨 아래 [이전] + [상세 분석 보기 →](카드를 열 때 패널 아래에서 올라옴) → `/dong/{dong_code}?industry_code=&from=search`. ⑫를 받는 동안 이름 · 구 · 순위 · 버튼은 그대로 두고 점수 · 지표 4칸만 막대(카드를 다시 그리지 않아 깜빡이지 않음) |

## 예외

- 점포 데이터 없음(⑫ store_count_latest null) → "○○ 데이터가 없어요" + 가까운 동네 2곳(경계 중심점 거리, ⑱에 점수가 있는 곳, 구 제한 없음).
- 예측 불가 → 카드의 영업 유지 · 매출에 "예측 불가". 영업 유지 대상이 아닌 업종은 영업 유지 칸에 점포 수 증감.
- geo_code가 없는 동(위례동 등 2013년 이후 신설) → 지도에 그리지 않고 목록 · 카드에 "지도에 표시되지 않음".
- ⑱ · ⑫ · ⑧ · ⑨ 실패 → 영역별 "다시 시도".
