# 직접찾기 (`/search`)

지도에서 행정동을 직접 고르거나 검색해 업종별 점수와 요약을 봅니다.

- 파일: `Search.jsx`, `Search.css`
- 상태(로컬): `query`, `picked`(선택한 동), `acOpen`, `big`/`sub`(업종), `sheetOpen`(모바일 시트), `more`, `focusGu`(지도에서 누른 구)
- 계산: `subScore`(업종별 점수·순위), `detailExtra().distShort`, `nearDongs`
- 지도: `DongLeafletMap` (지연 로딩)

## 요소

### 1. 지도 (화면 전체)
| 요소 | 내용 |
|---|---|
| 배경 | OpenStreetMap 타일(채도 낮춤) + 구 경계(점선)와 구 이름 |
| 핀 | 선택한 업종 기준 순위. 1~10위는 순위 배지 + 동 이름 + 점수 + 원형 후광(1~3위는 채워진 색), 그 아래는 점수만 있는 작은 점. 라벨이 겹치면 밀어내고 지시선으로 잇거나 순위 배지만 남김 |
| 핀 누르기 | 그 동을 선택 → 패널에 요약, 지도가 그 동으로 이동하고 동 경계 강조 |
| 구 누르기 | 그 구를 강조하고 구 안의 동 경계 표시 |
| 확대/축소 | 오른쪽 위 버튼, 휠, 핀치 |

### 2. 패널 상단 (`.search-top`)
| 요소 | 내용 |
|---|---|
| 손잡이 (모바일) | 시트 접기/펼치기 |
| 검색창 | "행정동 검색 · 예) 신림동, 성수". 포커스하거나 동을 고르면 파란 테두리, × 로 초기화 |
| 자동완성 (`.search-ac`) | 이름에 검색어가 들어간 동 최대 8개(일치 부분 굵게, 오른쪽에 구). Enter는 첫 항목 선택. 없으면 "‘○○’와 일치하는 서울 행정동이 없어요" |
| 대분류 칩 | 외식업 · 서비스업 · 소매업 |
| 세부 업종 칩 | 가로 스크롤. 바꾸면 순위·핀·점수가 다시 계산됨 |

### 3. 패널 본문 — 세 상태 중 하나

**(a) 상위 목록** (선택한 동 없음)
- "○○ 상위 5곳" + "지도 핀과 같은 순위예요"
- 행: 순위 배지(1~3위 파랑), 동 이름, 구 · 월매출 · 생존, 점수. 누르면 선택
- [10위까지 보기] / [접기]

**(b) 선택한 동 요약** (`Result`)
| 요소 | 내용 |
|---|---|
| ‹ | 목록으로 |
| 이름 · 구 · 업종 | 주거지역 배지 |
| 종합점수 · ♡ | 업종별 점수. ♡는 현재 업종과 함께 관심 등록 |
| 예상 생존 / 예상 월매출 | 80% 범위 (초록 / 파랑 타일). 예측 불가인 동은 "예측 불가" |
| 성장세 | 상승 초록 / 하락 빨강 / 정보 없음, "신뢰도 낮음" 배지 |
| 이 동네 상위 업종 | 점포 수 상위 4개 업종의 적음·보통·많음 3칸 막대 + 범례 |
| 안내 문구 | 80% 확률 범위 · 참고용 |
| [상세 분석 보기 ›] | `/dong/이름?from=search&sub=업종` |

**(c) 데이터 없는 동** (`NoData` — 청운효자동 등 종로구 8곳)
- "○○ 데이터가 없어요" + 가까운 동네 최대 3곳(같은 구 / 이웃 구). 누르면 그 동 선택
- 지도에는 점수 "—" 핀으로 표시

## 반응형

| | 데스크톱 (900px 이상) | 모바일 |
|---|---|---|
| 지도 높이 | 화면 − 헤더 | 화면 − 상단 바 − 탭바 |
| 패널 | 왼쪽 위 340px 카드, 항상 펼침 | 하단 시트. 접힘 150px(검색창+칩만) ↔ 펼침 최대 60% |
| 시트 열림 | — | 검색창 포커스, 동 선택, 손잡이 |
| 지도 맞춤 | 패널 폭(372px)만큼 왼쪽 여백 | 시트 높이만큼 아래 여백 |

## 예외

- GeoJSON을 못 받으면 지도 자리에 "지도 데이터를 불러오지 못했어요. 리스트로 확인해 주세요." — 패널은 그대로 쓸 수 있습니다.
- 지도 타일은 외부(OpenStreetMap) 서버에서 받습니다.
