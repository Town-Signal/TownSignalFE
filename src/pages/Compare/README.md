# 비교하기 (`/compare?dongs=동,동`)

관심 등록한 동네 중 같은 업종 최대 4곳을 표로 나란히 비교합니다.

- 파일: `Compare.jsx`, `Compare.css`
- 상태: 전역 `favs`, `favSub`, `last` / 로컬 `picked`(직접 고른 목록, `null`이면 기본 선택)
- 계산: `dongInfo`, `marginOf`, `growthColor`

## 요소

### 1. 제목
모바일 상단 바 "후보지 비교" / 본문 "관심 후보지 비교" + "관심 등록한 곳 중 최대 4곳을 골라 나란히 봐요."

### 2. 후보 칩 (`.cmp-chips`)
관심 동네마다 칩 하나: `✓/+ 동 이름 · 업종`.

| 상태 | 모양 / 동작 |
|---|---|
| 선택됨 | 파란 테두리·연파랑 배경, ✓. 누르면 해제 |
| 선택 가능 | 흰 배경, +. 누르면 추가 |
| 업종이 다름 | 회색·반투명, `not-allowed`, 툴팁 "○○와 업종이 달라 같이 비교할 수 없어요" |
| 4곳이 찼음 | 나머지 반투명, 눌러도 추가 안 됨 |

- 오른쪽에 "n/4 선택".
- **비교 기준 업종 = 처음 고른 후보지의 업종.** 아래에 "**○○** 기준으로 비교해요 · 업종이 다른 후보지는 함께 고를 수 없어요".
- 기본 선택: `?dongs=`가 있으면 그 목록, 없으면 첫 관심 동네와 같은 업종 최대 4곳.

### 3. 같은 구 안내 (`.cmp-info`)
선택한 동 중 같은 자치구가 있으면 "**A·B**는 같은 자치구라 임대료·예산 여유가 같은 값으로 보여요…" (둘 다 구 평균이라 오류가 아님).

### 4. 비교 표 (`.cmp-table`)
머리 행은 동 이름·구(누르면 상세). 행별 최고값에 "최고" 배지(2곳 이상 고른 경우).

| 항목 | 보조 설명 | 셀 | 최고 판정 |
|---|---|---|---|
| 종합점수 | 0~100 | 22px 파랑 / 예측 불가 배지 | 점수 |
| 생존 기간 | 80% 범위 | a~b개월 / 예측 불가 | 중앙값 |
| 월매출 | 80% 범위 | a~b만 / 예측 불가 | 중앙값 |
| 성장세 | 최근 1년 | 상승 초록·하락 빨강 / 정보 없음 | 증감률 |
| 임대료 | 구 평균 | 월 n만 원 (+신뢰도 낮음) / 정보 없음 | 판정 안 함 |
| 예산 여유 | 구 기준 (이력 없으면 "추천 후 표시") | ±n만 원 / 정보 없음 / 이력 없으면 — | 금액 |

### 5. 안내 문구
"범위는 80% 확률 범위예요. 예측은 참고용이에요…"

## 빈 상태

| 조건 | 화면 |
|---|---|
| 관심 동네 0곳 | ♡ 아이콘, "비교할 관심 동네가 없어요", [조건으로 추천받기] [직접 찾아보기] |
| 선택 0곳 | "비교할 동네를 골라 주세요" (칩은 그대로) |

## 반응형

- 표는 카드 안에서 가로 스크롤하고 항목 열(모바일 96px / 데스크톱 112px)은 왼쪽에 고정됩니다. 동 열은 최소 140px.
- 칩은 줄바꿈되며 높이 44px(터치 타깃).
