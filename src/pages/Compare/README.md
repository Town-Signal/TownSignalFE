# 비교하기 (`/compare?dongs=dong_code&industry_code=`)

관심 등록한 동네(+ 상세에서 넘어온 현재 동) 중 같은 업종 최대 4곳을 ⑭로 나란히 비교합니다(명세 10.6).

- 파일: `Compare.jsx`, `Compare.css`
- 상태: 전역 `favs`(dong_code), `favIndustry`, `last`(rec_id) / 로컬 `picked`(직접 고른 목록, `null`이면 기본 선택), `cmp`(⑭ 응답)
- API: ⑭ `POST /regions/compare { dong_codes, industry_code, rec_id? }`, 칩 이름은 업종이 있으면 ⑫(dong_name · district_name), 없으면 ⑧ · ⑨(`lib/dongNames`), 업종명은 ⑩

## 요소

| 요소 | 내용 |
|---|---|
| 후보 칩 | 동명 + "구 · 업종". 처음엔 첫 후보와 같은 업종 앞 4곳 선택. 업종이 다른 칩 · 업종을 모르는 칩은 흐리게 · 선택 불가(툴팁) |
| 기준 업종 | "○○ 기준으로 비교해요" — 처음 고른 후보의 업종 |
| 같은 구 안내 | district_code가 같은 동이 2곳 이상이면 "같은 자치구라 임대료 · 예산 여유가 같은 값" |
| 비교 표 | 종합점수 · 예상 생존(80% 범위) · 예상 월매출(80% 범위) · 성장세 · 임대료(월) — ⑭ monthly_rent 만 원/월, 보조 줄에 추정 초기 임대비용(보증금 + 월세 3개월), 신뢰도 낮음 배지 · 예산 여유. 항목별 최고값에 "최고"(임대료는 월세가 낮은 쪽, 동률이면 표시 안 함) |
| 1곳만 선택 | 빈 열에 "비교할 상권을 1곳 더 골라주세요" |
| 하단 | 면책 문구 + 상권 지표 기준 분기 |

## 예외

- 관심 0곳(넘어온 동도 없음) → "비교할 관심 동네가 없어요" + [조건으로 추천받기] · [직접 찾아보기].
- 예측 불가 → "예측 불가", 도봉구 임대료 · 예산 여유 → "정보 없음", rec_id 없음 → "추천을 거치면 표시돼요".
- ⑭가 REC_NOT_FOUND → ts-last의 rec_id만 지우고 rec_id 없이 다시 부른다. 그 밖 실패 → "다시 시도".
